## 分析結果
1. current_day_mon (正確)
- 規格：週一為 0，週日為 6。
- 程式碼：now.weekday() 在 Python 中回傳 0 (週一) 到 6 (週日)。
- 結論：邏輯一致，無需修改。
2. current_day_sun (有誤)
- 規格：週日為 1，週一為 2，...，週六為 7。
- 原程式碼：current_day_mon + 2
    - 週一 (0) -> 0 + 2 = 2 (正確)
    - 週日 (6) -> 6 + 2 = 8 (錯誤，應為 1)
- 修正邏輯：使用模數運算來處理循環。
    - 公式：(weekday + 1) % 7 + 1
    - 週日 (6) -> (6 + 1) % 7 + 1 = 0 + 1 = 1 (正確)

```python
# 修改前
current_day_sun = current_day_mon + 2

# 修改後
# 根據規格：星期日=1, 星期一=2, ... 星期六=7
current_day_sun = (current_day_mon + 1) % 7 + 1
```
